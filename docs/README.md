# Dokumentation

Diese Dateien bilden das überprüfbare Projektgedächtnis. Nicht jede Aussage
hier ist eine API-Garantie; Recherchebeobachtungen sind als solche gekennzeichnet.

| Datei | Inhalt |
| --- | --- |
| `PROJECT_STATUS.md` | Ist-Zustand, Tests, Einschränkungen, nächste Schritte |
| `ARCHITECTURE.md` | Komponenten und Zuständigkeiten |
| `API_RESEARCH.md` | Offizielle Regeln und beobachtetes Live-Verhalten |
| `PROGRAM_SOURCES.md` | Zusätzliche Programmchecks, historische Archive und belegte Vorgangsanalysen |
| `DATA_MODEL.md` | Lokale Tabellen und Provenienz |
| `METHODOLOGY.md` | Anforderungen an spätere politische Vergleiche |
| `COMPARISON.md` | Deutsche Vergleichsanfragen, PDF-Belege, amtliche Quellen und Versprechenprüfung |
| `decisions/` | Begründete Architekturentscheidungen |

Bei Widersprüchen Quellcode und Tests untersuchen, nicht Dokumentation blind
als Wahrheit übernehmen. Änderungen an Aussagen mit tatsächlichen Prüfungen belegen.
