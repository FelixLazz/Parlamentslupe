# Ausgewählte Originalprogramme

`compare --online` lädt nur das ausgewählte, API-verlinkte und bei
abgeordnetenwatch gehostete Programm. Alternativ `--program-file ORIGINAL.pdf`.

Automatisch verwaltet: `PROGRAMM_ID/SHA256.pdf` und `PROGRAMM_ID/SHA256.json`.
Die PDF bleibt unverändert, die JSON enthält Quelle, Herkunft, IDs, UTC-Importzeit
und Seitentexte. Nicht von Hand verändern; der nächste Vergleich prüft das Original.

Mehrere Dokumentversionen erfordern eine explizite lokale Dateiauswahl.
Keine OCR. Keine automatische Veröffentlichung oder CC0-Behauptung für PDFs.
Details: `docs/COMPARISON.md`.
